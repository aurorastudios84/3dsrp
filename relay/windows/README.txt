3DSRP Companion for Windows

Download and run 3DSRP-Companion.exe. No administrator installer or extra runtime
is required. Pair your PS4/PS5 in the app, then enter the PC's displayed Wi-Fi
IPv4 address in 3DSRP Relay on the handheld. Keep both on the same trusted LAN.
Existing settings and pairing data stay in the per-user application data folder.

The application is unsigned. Managed Windows policies may prevent execution.
Do not disable organizational security controls to run it.

Startup logs are local only. Automatic startup-log uploads have been removed.
Optional handheld usage statistics are forwarded only under handheld consent.
Do not publish pairing data or logs containing local network/account details.
