WINDOWS COMPANION CORRESPONDING SOURCE

The source archive preserves this layout:
  relay/windows/                       Windows implementation and packaging
  relay/common/                        shared release 42 protocol/processing
  relay/vendor/chiaki-upstream/         pinned Chiaki core with existing patches
  relay/vendor/mbedtls/                 existing Android crypto dependency
  relay/vendor/libjpeg-turbo-3.1.3/     existing JPEG dependency
  relay/android/app/src/main/cpp/       shared stream profile, protobuf and stubs
  source/chiaki-ng/third-party/         GF-Complete, Jerasure and nanopb

On Ubuntu 24.04 or a compatible Debian system, have Python 3, CMake, GNU Make,
GCC, g++, tar, curl, dpkg-deb and APT available. For a local compiler/tooling
installation without root, run:

  cd relay/windows
  ./bootstrap-toolchain.sh
  python3 fetch-deps.py
  ./build.sh
  ./package.sh

Alternatively use a system MinGW-w64 POSIX-thread toolchain and wixl/msitools.
The bootstrap downloads the toolchain from your configured APT repositories
and extracts packages into toolchain/root. It does not modify the OS.

Codec sources are pinned to FFmpeg 7.1.5 (latest maintenance release on its
branch checked on 2026-11-06) and Opus 1.6.1. fetch-deps.py verifies archive
SHA-256 hashes. The archive includes those exact source tarballs for offline
codec builds. Other vendored sources accompany the archive in full.
FFmpeg is built as static H.264-only libavcodec/libavutil, without network,
programs, external auto-detected libraries, GPL, or nonfree components.
Opus and libjpeg-turbo are built statically. JPEG SIMD assembly is disabled
for a straightforward cross build. No compressed/self-extracting executable
packer is used; strip only removes build/debug symbols.

EXE: dist/3DSRP-Companion.exe
MSI: dist/3DSRP-Companion-42.0.3-x64.msi
ZIP: dist/3DSRP-Companion-42.0.3-x64-portable.zip

The Windows application uses only inbox Windows DLLs. Application libraries
and C++ support are statically linked. No additional runtime installation is
required. The app manifest is asInvoker. The MSI is per-user, installs under
LocalAppData/Programs and uses HKCU registry entries. Its summary WordCount
contains the non-elevated-package flag (8) and compressed flag (2).

Production signing: on Windows use sign.ps1 with your trusted certificate
thumbprint to sign dist/3DSRP-Companion.exe; rebuild the MSI with package.sh;
then sign the MSI with SignTool and regenerate hashes/ZIP. Do not re-run
build.sh after signing unless you intend to replace the signed EXE.
No certificate or private key is included in source or build artifacts.

This build was cross-compiled using GCC/MinGW-w64 13.2 POSIX threading,
CMake 3.28.3 and wixl/msitools 0.103. The release source archive includes SOURCE-SHA256SUMS.txt. See
docs/RELEASE-CHECKS.md for validation. Windows code signing has not been performed.
Build success does not establish Windows runtime or antivirus results.

Preview 42.0.3 adds automatic local discovery through standard IP Helper
adapter/neighbor enumeration and UDP broadcast/unicast; it uses only inbox
Windows APIs and does not install a service, driver, or firewall rule.
