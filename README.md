# 3DSRP

A homebrew PS4/PS5 Remote Play client for New Nintendo 3DS, New 3DS XL/LL and
New 2DS XL, based on [Chiaki-ng](https://github.com/streetpea/chiaki-ng).

See the [CIA build instructions](source/README.md).
